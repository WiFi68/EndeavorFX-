EndeavorFX

Adaptive cinematic lighting for Roblox Studio.

Analyze the scene. Understand the shot. Enhance the image.

EndeavorFX is a free, open-source Roblox Lua lighting system designed to analyze a scene and automatically build a cinematic lighting setup around it.

There is no official plugin.

The project provides the Lua code so developers can run it, modify it, fork it, and build their own tools around it.

«Built by WiFi. Improved by everyone.»

---

✨ Features

- 🎥 Shot Analysis — analyzes the active camera and composition
- 🧠 Adaptive Lighting — adjusts exposure, ambient lighting, and environment response based on the scene
- 🎯 Auto Focus — multi-ray camera focus analysis
- 💡 Light Analysis — takes existing lights into account
- 🧱 Material Awareness — considers materials such as Metal, Glass, and Neon
- 🌫️ Atmosphere Solver — dynamically configures atmospheric effects
- 🎨 Cinematic Effects — Bloom, Color Correction, Depth of Field, Sun Rays, and Color Grading
- 🌅 Time of Day Presets — Dawn, Morning, Noon, Golden Hour, Dusk, Night, and Studio
- 🎭 Mood Presets — Cinematic, GoldenHour, Studio, Dreamy, Horror, Neon, and Night
- 💾 Backup & Restore — protects the original lighting configuration
- ⚙️ Quality Modes — control the amount of scene analysis performed

🚀 Getting Started

Roblox Studio

1. Open your Roblox Studio project.
2. Open the Command Bar.
3. Copy the EndeavorFX Lua script.
4. Paste it into the Command Bar.
5. Run it.
6. Configure the settings.
7. Solve the shot.

That's it.

No plugin installation.

No external application.

No paid software.

Just Lua.

EndeavorFX is actively evolving.
