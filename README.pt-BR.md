EndeavorFX

Iluminação cinemática adaptativa para Roblox Studio.

Analise a cena. Entenda o plano. Melhore a imagem.

EndeavorFX é um sistema de iluminação Lua livre e de código aberto para Roblox, projetado para analisar uma cena e construir automaticamente uma configuração de iluminação cinemática ao seu redor.

Não há plugin oficial.

O projeto fornece o código Lua para que desenvolvedores possam executá-lo, modificá-lo, fazer um fork e construir suas próprias ferramentas ao seu redor.

«Construído por WiFi. Melhorado por todos.»

---

✨ Recursos

- 🎥 Análise de Plano — analisa a câmera ativa e a composição
- 🧠 Iluminação Adaptativa — ajusta exposição, iluminação ambiente e resposta do ambiente com base na cena
- 🎯 Foco Automático — análise de foco de câmera com múltiplos raios
- 💡 Análise de Luzes — leva em conta as luzes existentes
- 🧱 Consciência de Materiais — considera materiais como Metal, Glass e Neon
- 🌫️ Solucionador de Atmosfera — configura dinamicamente efeitos atmosféricos
- 🎨 Efeitos Cinemáticos — Bloom, Color Correction, Depth of Field, Sun Rays e Color Grading
- 🌅 Predefinições de Hora do Dia — Dawn, Morning, Noon, Golden Hour, Dusk, Night e Studio
- 🎭 Predefinições de Clima — Cinematic, GoldenHour, Studio, Dreamy, Horror, Neon e Night
- 💾 Backup e Restauração — protege a configuração de iluminação original
- ⚙️ Modos de Qualidade — controlam a quantidade de análise de cena realizada

🚀 Começando

Roblox Studio

1. Abra seu projeto do Roblox Studio.
2. Abra a Command Bar.
3. Copie o código de `src/EndeavorFX.lua` neste repositório.
4. Cole na Command Bar.
5. Execute.
6. Configure as definições.
7. Resolva o plano.

É isso.

Sem instalação de plugin.

Sem aplicação externa.

Sem software pago.

Apenas Lua.
